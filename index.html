Hướng dẫn sử dụng SlideEdu Việt

Tạo slide trình chiếu giảng dạy, học tập, soạn giáo án, tạo đề kiểm tra và các tính năng hổ trợ khác hữu ích, nhanh chóng với AI

1. Giới thiệu

SlideEdu Việt là một công cụ hỗ trợ tạo slide bài giảng, giáo án, đề kiểm tra, bài tập, tóm tắt, tạo hội thoại,... dựa trên AI. Người dùng có thể nhập chủ đề, các yêu cầu về nội dung và nhận về mã LaTeX, sau đó biên dịch thành PDF sẵn sàng sử dụng. Hiện tại chỉ mới ra phiên bản chạy trên máy tính cho hệ điều hành Windows. Xem hướng dẫn cách thực hiện để AI cho sản phẩm tốt nhất tại link:...

2. Cài đặt

  1. Tạo một thư mục trên máy tính hoặc laptop đặt tên tùy ý (SlideEdu Việt).
  2. Tải các file SlideEdu.v1.0.0.exe và key.txt vào thư mục vừa tạo.
  3. Mở file key.txt để lấy key.
  4. Khởi chạy ứng dụng: SlideEdu.v01.0.0.exe .
  5. Nhập key SlideEdu111yenthanhnghean lấy từ key.txt nếu ứng dụng yêu cầu.
  6. Bạn có thể không làm như trên mà tải file SlideEdu.rar xuống máy. Giải nén vào thư mục bạn muốn rồi chạy file SlideEdu.v01.0.0.exe .
  7. Lưu ý nếu máy bạn có phần mềm kiểm tra virus thì cần điều chỉnh để cho phép chạy các file .exe ở trên.

Tải các file cần thiết:

SlideEdu.exe key.txt SlideEdu.rar

3. Các thành phần chính của giao diện

  • Tiêu đề & Chủ đề: Nhập tên bài học, chủ đề.
  • Editor LaTeX: Soạn và chỉnh sửa mã LaTeX.
  • Chat AI: Đề xuất nội dung hoặc chỉnh sửa.
  • Nút chức năng: Generate Slide, Compile PDF, Open PDF,…

4. Hướng dẫn sử dụng

  1. Chọn template phù hợp.
  2. Nhập tiêu đề & chủ đề (chủ đề càng cụ thể, nội dung trình chiếu càng đầy đủ. Xem hướng dẫn nhập chủ đề tốt nhất tại địa chỉ:...).
  3. Nhấn Generate Slide để lấy LaTeX.
  4. Chỉnh sửa LaTeX nếu muốn.
  5. Nhấn Compile PDF.
  6. Open / Save PDF hoặc mở Overleaf để điều chỉnh nội dung.
  7. Sử dụng Chat AI để cải thiện nội dung.

5. Mẹo & Ghi chú

  • Lưu prompt và LaTeX để tránh mất dữ liệu.
  • Dùng template phù hợp để tiết kiệm thời gian.
  • Nếu lỗi compile PDF → kiểm tra cú pháp LaTeX.
  • API key SLIDE_EDU_KEY phải hợp lệ.
Lưu ý: SlideEdu yêu cầu Internet để kết nối AI.

6. Flow tổng thể

  1. Nhập API key.
  2. Generate LaTeX từ chủ đề.
  3. Chỉnh sửa trong editor.
  4. Compile → PDF.
  5. Chat AI hỗ trợ thêm nội dung.
