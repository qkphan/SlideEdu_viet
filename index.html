Hướng dẫn sử dụng SlideEdu

Tạo slide hỗ trợ giảng dạy học tập, soạn giáo án, đề kiểm tra nhanh chóng với AI

1. Giới thiệu

SlideEdu là một công cụ hỗ trợ tạo slide, bài tập, tóm tắt, và giáo án học tập dựa trên AI. Người dùng có thể nhập chủ đề và nhận về mã LaTeX, sau đó biên dịch thành PDF sẵn sàng sử dụng.

2. Cài đặt

  1. Khởi chạy ứng dụng: SlideEdu.exe
  2. Nhập key SLIDE_EDU_KEY được kèm trong key.txt nếu ứng dụng yêu cầu.

Tải các file cần thiết:

SlideEdu.exe key.txt SlideEdu.rar

3. Các thành phần chính của giao diện

  • Tiêu đề & Chủ đề: Nhập tiêu đề slide và chủ đề bài học.
  • Prompt: Khu vực nhập câu lệnh chi tiết cho AI.
  • Editor LaTeX: Hiển thị code LaTeX tạo slide hoặc bài tập.
  • Chat AI: Giao tiếp trực tiếp với AI để gợi ý nội dung hoặc chỉnh sửa.
  • Nút chức năng: Generate Slide, Compile PDF, Mở PDF, Lưu PDF, Mở Overleaf.

4. Hướng dẫn sử dụng

  1. Chọn template: Chọn template phù hợp (Slide, Bài tập, Giáo án,...)
  2. Nhập tiêu đề & chủ đề: Điền thông tin vào Tiêu đề và Chủ đề.
  3. Soạn prompt: Nội dung slide được AI tạo tự động.
  4. Generate slide: Nhấn Generate Slide → AI trả về LaTeX code.
  5. Chỉnh sửa LaTeX: Tùy chỉnh mã nếu muốn điều chỉnh nội dung hoặc định dạng.
  6. Compile PDF: Nhấn Compile PDF → tạo file PDF.
  7. Mở & lưu file:
    • Nhấn Open PDF để xem.
    • Nhấn Save PDF để lưu vào thư mục chọn.
    • Nhấn Open in Overleaf để chỉnh sửa trực tuyến.
  8. Chat AI hỗ trợ: Sử dụng khung chat để AI cải thiện nội dung hoặc tạo bài tập bổ sung.

5. Mẹo & Ghi chú

  • Luôn lưu prompt và LaTeX code để tránh mất dữ liệu.
  • Sử dụng template phù hợp để giảm thời gian chỉnh sửa.
  • Nếu lỗi compile PDF, kiểm tra cú pháp LaTeX.
  • API key SLIDE_EDU_KEY cần hợp lệ để kết nối AI server.
Lưu ý: SlideEdu yêu cầu kết nối Internet để liên hệ với AI server.

6. Flow tổng thể

  1. Nhập API key nếu chưa có.
  2. Nhập tiêu đề và chủ đề → Generate LaTeX code.
  3. Hiển thị code trong editor → chỉnh sửa tùy ý.
  4. Compile LaTeX → PDF → mở hoặc lưu file.
  5. Chat AI hỗ trợ tương tác và gợi ý nội dung.
